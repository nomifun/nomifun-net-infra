# NomiRelay 接入文档

面向**外部团队**：你要把自己的系统接到一台 NomiRelay 上，手里只有这个仓库和一台机器。

这份文档描述的是**代码当前的实际行为**，不是设计意图。凡是「看起来能用但其实不能」的
地方都会被显式点出来 —— 那是本文档最有价值的部分。

设计意图见 [`docs/superpowers/specs/2026-08-07-nomirelay-design.md`](../superpowers/specs/2026-08-07-nomirelay-design.md)（规范性文档）。
两者不一致时**以本文档为准**，并请提一个 issue —— 那说明规格已经漂了。

## 三件先知道比后知道好的事

**1. 控制台是明文 HTTP，默认只绑 loopback。** 那是正确的默认。要远程访问只有两条路：
SSH 隧道，或者前置一个做 TLS 终止的反代 **并显式声明它**（`-console-behind-tls-proxy`）。
声明错了会得到一个很难认的现象：登录返回 200，下一个请求 401。见 [2](02-deployment.md)。

**2. 没有 API 令牌。** 服务间集成拿到的是**那把唯一的管理员口令**，而同一个会话
还能删掉全部隧道、下载支持包。没有角色、没有分权。见 [3](03-api.md) 与
[9](09-known-gaps.md)。

**3. v1 里所有隧道都必须有一个 agent 承载。** 「中继自己拨号」没有实现。
未绑定的隧道会在恰好一个 agent 在线时自动绑上，在那之前状态如实报 `pending`。
